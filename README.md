## Publicação no GitHub Pages

1. Crie um repositório novo.
2. Faça upload do `index.html` e da pasta `assets` para a RAIZ do repositório.
3. Em Settings > Pages, selecione Deploy from a branch.
4. Escolha a branch principal/main e a pasta `/ (root)`.
5. Salve.

Não coloque o `index.html` em uma pasta diferente da pasta `assets`, pois os caminhos das imagens são relativos (`assets/...`).
