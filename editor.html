Editor visual de LPsAds&Ads

Escolha uma LP para editar

Use a lista no topo para abrir uma das LPs do repositório, ou clique em Abrir do computador para abrir um index.html que você já baixou.

Como usar

  • Clique em qualquer coisa da página para selecionar. O painel Elemento mostra o que dá para mudar.
  • Duplo clique num texto para reescrever. Enter conclui, Shift+Enter quebra a linha.
  • Bloco maior pega o conjunto em volta (ex.: do título para a seção inteira). Os botões do "caminho" fazem o mesmo.
  • Subir / Descer muda a ordem: seções inteiras, cards, etapas, números, selos, parágrafos. Para trocar o formulário de lado no topo, selecione o formulário e clique em Subir.
  • Aplicar em decide se a mudança vale para todas as telas ou só para computador, tablet ou celular. Use os botões do topo para conferir cada tela.
  • A aba Cores troca uma cor na página inteira de uma vez (ex.: o laranja da marca).
  • Elementos ocultos somem da tela. Para trazer de volta, use a aba Ocultos.
  • Ctrl+Z desfaz. O editor guarda um rascunho automático neste navegador.

Para publicar

  1. Clique em Baixar index.html.
  2. No GitHub, entre na pasta da LP → Add file → Upload files → arraste o arquivo → Commit changes.
  3. Se trocou alguma imagem, suba também o arquivo da imagem na pasta assets da LP.
  4. Em 1 a 2 minutos a página publicada atualiza.

O que o editor protege

Scripts, tags e o formulário não rodam durante a edição e voltam intactos no arquivo salvo. Os ajustes ficam num bloco separado (lpe-visual), então reabrir o arquivo no editor traz tudo de volta.
