# LP Infraestrutura — Menndel & Melo

Pacote pronto para GitHub Pages.

## Estrutura
- `index.html`
- `assets/`

## Pasta recomendada no repositório
`infraestrutura/`

Mantenha `index.html` e `assets/` lado a lado dentro da pasta `infraestrutura`.
Não mova os arquivos de `assets/` para a raiz do repositório.

Padrão aplicado: títulos compactos, CTAs em 16px, seção Sobre institucional preservada, três frentes de atuação (ANEOR, ANETRAMS e contratos administrativos/Reforma Tributária).
